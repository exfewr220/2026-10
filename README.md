## 条款里藏着的几个限制

这几条不会写在购买页最显眼的位置，但直接影响使用体验，很多推荐文章没讲清楚。

**CPU 公平使用政策。** 官方不允许长时间占满 100% CPU。同样 2GB 内存、40GB 硬盘的规格，Basic 系列限制为 75% 单核使用率，CN2 GIA-E 系列则可用 100% 单核加 50% 的第二核。打算长期跑满 CPU 挂任务的话，同价位的 E-Commerce 系列余量更大。

**迁移机房会动流量。** KVM 和 CN2 系列可以在约 8 个机房间切换，但迁到 CN2 机房后，月流量按原来的三分之一计算——1TB 直接变 333GB 左右。香港和日本的高价套餐则完全不可迁移，买前要确定机房。

**付款周期各有差异。** CN2 GIA-E 低配不支持月付，迪拜系列则是月付到年付全周期都开放，想按月灵活试错的读者反而可以看它。迪拜套餐的代价在流量：价格与 CN2 GIA-E 同档，月流量只有一半，而且不支持 IPv6，依赖 v6 或双栈部署的方案要绕开。

**续费时间窗。** 账单在服务到期前 7 天生成，续费宽限期也是 7 天，到期不续会被暂停，别忘了处理。

## 机房和线路：便宜的代价在哪

搬瓦工的价格差，很大程度是在为线路买单。同是 1GB 内存、20GB 硬盘、1TB 流量，KVM 年付 $49.99、CN2 GIA-E 年付 $169.99、香港 CN2 GIA 月付就要 $89.99，三档价格差出十倍以上。

CN2 GIA-E 值这个差价的地方在于两点：一是三网双向优化的 CN2 GIA 线路，电信、联通、移动晚高峰表现都明显好于普通线路；二是可以在洛杉矶 DC6、DC9、日本软银 JPOS_1、荷兰 EUNL_9、圣何塞、加拿大等 11 到 12 个机房间随时切换，感觉哪个慢就迁走，不用换机器重买。KVM 和 CN2 系列虽然也能切机房，但可选的都是普通线路，切换的意义小得多。

再往上，香港和日本软银属于延迟和带宽的极致体验，独享 1Gbps 起步，月付价格决定了它只适合预算充足、对速度极其敏感的场景。预算敏感的读者在这部分不用纠结，看看就好。

## 购买流程与付款

流程本身不复杂，真正的新手障碍通常在第一步：搬瓦工的官方主域名在中国大陆通常无法直接访问，官方提供多个镜像域名，具体哪些可用以官方说明为准，不要把任何单个镜像地址当成永久入口。

购买按这个顺序走：

1. 通过镜像域名进入官网，选好套餐和计费周期，加入购物车；
2. 结算页如有优惠码就填（目前大概率没有），确认金额无误后再提交；
3. 注册账户，只需要一个邮箱；
4. 选择支付方式，支持支付宝、银联在线、PayPal 和国际信用卡；
5. 收到开通邮件后进入 KiwiVM 控制面板，可以重装系统、重置密码、迁移机房、做快照，系统镜像覆盖 AlmaLinux、Debian、Ubuntu、CentOS 等主流发行版。

所有套餐都是自助管理（self-managed），官方不提供运维服务，出问题靠自己在面板和知识库里解决，这也是它能把价格压下来的原因之一。前面说过，常规套餐续费价等于购买价，第一年多少钱、以后每年就还是多少钱，这笔账在付款前就可以算死。

**最便宜一年总共要花多少钱？** 常规底线是 20G KVM 年付 $49.99，约 300–360 元人民币，平均每月合 25–30 元。如果恰逢限量版 MINICHICKEN 补货，$19/年能压到更低，但不可控。

**1GB 内存的便宜套餐够用吗？** 跑个人博客、小型网站、学习环境够用，1TB 月流量对这类场景绰绰有余。要跑数据库、编译任务或多个服务，建议从 2GB 内存起步。

**官网打不开怎么办？** 换官方镜像域名访问，具体可用镜像以官方说明为准。

**便宜套餐国内访问慢怎么办？** 两个选择：接受它作为纯海外业务或练手机器；或者升级到 CN2 GIA-E 系列。GIA-E 支持机房切换，可以先买再根据实际体验迁移。
